SARAH TRAITEUR — VERSION GITHUB PAGES

1. Créez un dépôt GitHub, par exemple: sarah-traiteur
2. Envoyez TOUS les fichiers contenus dans ce dossier à la RACINE du dépôt.
   index.html doit être visible directement dans la racine.
3. GitHub > Settings > Pages
4. Source: Deploy from a branch
5. Branch: main / (root) puis Save
6. Attendez 1 à 5 minutes.

Votre URL sera généralement:
https://VOTRE-PSEUDO.github.io/sarah-traiteur/

Le fichier .nojekyll est inclus pour GitHub Pages.
Les chemins des images/CSS/JS sont compatibles avec un dépôt de type /sarah-traiteur/.

FORMULAIRE
Le formulaire utilise FormSubmit et envoie vers sarah.traiteur.be@gmail.com.
Lors du premier test, un e-mail d'activation FormSubmit peut être envoyé à cette adresse.

SEO
Cette version de TEST n'inclut volontairement pas de canonical absolu, car l'URL GitHub n'est pas encore connue.
Quand le domaine final sera choisi, ajoutez le canonical, sitemap.xml et les URL absolues Schema.org avec le domaine final.
