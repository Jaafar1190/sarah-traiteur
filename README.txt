SARAH TRAITEUR — SITE STATIQUE PRÊT À PUBLIER

Contenu :
- index.html : page principale
- styles.css : design responsive
- script.js : menu mobile, animations, navigation active, formulaire e-mail
- mentions-legales.html
- politique-confidentialite.html
- assets/ : images, logo, favicon, image Open Graph

Publication :
1. Envoyer tous les fichiers et le dossier assets à la racine de l’hébergement.
2. Le fichier d’entrée est index.html.
3. Pour un hébergement Hostinger, placer le contenu dans public_html.
4. Vérifier les informations d’entreprise dans mentions-legales.html et compléter le numéro BCE/TVA et l’adresse du siège avant mise en ligne.
5. Remplacer les liens Instagram/Facebook "#" dans le footer par les URL officielles dès qu’elles sont connues.

Formulaire :
Le formulaire ouvre l’application e-mail du visiteur vers sarah.traiteur.be@gmail.com. Aucun backend n’est requis.

SEO / AIO (optimisation assistants IA)
- Le contenu est structuré pour les recherches "traiteur marocain", "traiteur mariage" et "traiteur événementiel" en Belgique.
- Données structurées JSON-LD : LocalBusiness/FoodEstablishment, WebSite, Service et FAQPage.
- FAQ visible ajoutée pour répondre directement aux questions fréquentes des visiteurs et moteurs de réponse.
- Meta robots, Open Graph, Twitter Card, hreflang fr-BE, canonical relatif et optimisation des images ajoutés.
- robots.txt inclus.
- Après choix du domaine définitif, remplacer les URL relatives des balises canonical/JSON-LD par l'URL absolue finale et créer un sitemap.xml avec ce domaine.
